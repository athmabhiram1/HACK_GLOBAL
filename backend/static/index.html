01 / METHOD

THREE MOVES, zero mercy.

No frameworks, no magic. A hardened intake, five sandboxed gates, a verdict engine that only trusts evidence.

01

Paste a URL

Any public GitHub/GitLab repo. Intake is SSRF-hardened: allowlisted hosts only, DNS-resolve guard against metadata IPs, 50MB cap, submodules disabled, dash-prefixed inputs rejected before a single byte is cloned.

protocol.ext=never
metadata → REJECT
02

Run the gates

Secrets → Deps → Docs → Cost → Build, each in a throwaway sandbox on one 2GB VM. The queue holds exactly one job: a second submit gets an honest 429 and a retry hint — never a parallel build.

queue=maxsize 1
--cap-drop=ALL

Ship the evidence

0–100 score, SHIP / FIX / BLOCKED, and proof: downloadable SARIF, redacted log tail, cited fix links, cost simulation. The LLM summarizes redacted results in two sentences — it never decides anything.

exit 0 = SHIP
exit 1 = FIX / BLOCKED
02 / GATES

FIVE GATES, one verdict.

Every gate has an offline fallback and returns evidence, never a 500. All five decide; the extras never do. Click a row to inspect.

Scans the snapshot for leaked keys and tokens, redacts every match before it touches the UI or logs, and attaches a downloadable SARIF 2.1.0 report. Findings are labeled "potential exposure — not verified active key." Base64 decode depth is capped at zero so a hostile repo can't OOM the 2GB host.

gitleaks detect --source /repo --redact --max-decode-depth=0 --report-format sarif
Fallback: allowlist path note still verdicts. Raw secrets are never logged, rendered, or cached — anywhere.

Parses manifests without installing anything. One batched OSV querybatch call (24h cache) covers every dependency; typosquats are flagged with a C-extension Levenshtein ≤2 against the top-200; ast import analysis boosts severity for reachable code paths.

POST api.osv.dev/v1/querybatch — 1 call for N deps
Fallback: offline sample requirements.vuln.txt verdicts when OSV is unreachable.

Diffs recent commits against README endpoints and flags stale documentation with exact file:line + character offset, plus a copyable proposed patch. No evidence? It refuses with a stated reason instead of inventing one.

git diff HEAD~3 -- README.md docs/ src/
Fallback: {refused:true, reason} — an honest refusal beats a confident hallucination.

Reads instances, sizes and volumes with a read-only key held in memory only, then flags idle CPU, unattached volumes and oversized plans — with monthly dollars saved, kg CO₂ avoided, and a ready-to-paste downgrade command.

GET api.vultr.com/v2/instances | /sizes | /volumes
Fallback: ?demo=1 synthetic data — the $ math always renders.

Clones hardened (depth-1, 60s), builds with throttled BuildKit and a 300s kill, runs jailed — 512MB RAM, 0.5 CPU, read-only root, all capabilities dropped, uid 65534 — then probes /healthz with a 2s timeout. Cleanup runs even on failure. On timeout: pre-recorded DEMO REPLAY logs, clearly labeled.

--memory=512m --cpus=0.5 --pids-limit=64 --read-only --cap-drop=ALL -u 65534
Fallback: timeout → FIX/BLOCKED + replay log. Never a hang, never a 500.

Two extras that add evidence and input — and never touch the verdict. Exa attaches ≤2 cited fix links per critical CVE; Wispr fills the repo box from your voice (16kHz wav, converted client-side). Missing keys? They skip silently.

Rule: verdict comes from the 5 core gates. Always. Extras are witnesses, not judges.

05 / SAFETY
TRUST NOTHING, prove everything.
We execute strangers' code for a living. Here is the jail.

    

      
S1SSRF hardening
HTTPS-only allowlist, DNS resolved and checked against private/metadata ranges, redirect-following off, dash-prefixed inputs rejected.
DOCKER-USER → 169.254.169.254 REJECT

      
S2Sandbox jail
Every build runs read-only, all Linux capabilities dropped, nobody user, hard memory/CPU/PID ceilings on an isolated bridge network.
--memory-swap=512m --pids-limit=64

      
S3Secrets hygiene
gitleaks --redact before anything renders; log tails redacted like SARIF; API keys server-side only — never in image, bundle, logs or frontend.
--max-decode-depth=0 (OOM guard)

      
S4Never a 500
Every gate has a fallback: OSV offline sample, cached verdicts, DEMO REPLAY logs on build timeout, static summary when Inference is down.
gate fail → FIX / BLOCKED + evidence

      
S5Queue of one
A single asyncio worker bound to app lifespan. Backpressure is honest: a second job gets 429 + a retry hint instead of OOM-killing a 2GB box.
asyncio.Queue(maxsize=1) · to_thread only

      
S6LLM never gates
Vultr Inference writes a 2-sentence summary of redacted results with a 10s timeout and a static template fallback. Verdicts come from evidence.
system prompt: "No new verdicts."
