# ARCHIVED — submission checklist (starter pattern, history only; live shape is in `docs/05-submission.md`)

Submit on Vultr Community before the regional close; late = rejected; moderator reviews before Showcase.
Pre-checks: every member checked in + Community accounts; public repo + README setup steps; no keys/`.env`; live Vultr link works in private window; arch diagram ready.
Form: name, 1–2 sentence desc, diagram, domain, tags (Hackathons), repo link, live URL, stack, overview, Vultr-use line, teammates, Build-for = HackGlobal 2026 (required or invisible).
Mistakes: private repo, localhost link, missing event select, last-minute submit.
